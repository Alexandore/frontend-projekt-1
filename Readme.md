# [Historiskt CV]

## Om sidan

Vad handlar sidan om, och vem är den till för? Två–tre meningar.
Sidan är ett CV för den florentinska bankmannen Lorenzo de Medici, med hans erfarenheter och kompetenser samt finns det ett personligtbrev som används för att förstärka Lorenzos jobb ansökan, den är till för arbetsgivaren han vill söka jobb hos.

## Skiss

Länk eller hänvisning till skissfilen i repot.
Skiljer sig den färdiga sidan från skissen? Vad ändrades och varför?
Jag gjorde först skisser för att planera hur mitt CV skulle se ut. Under arbetets gång ändrade jag layouten några gånger eftersom jag inte var helt nöjd med hur sidan såg ut. Den färdiga sidan skiljer sig därför lite från mina första skisser.

## Funktionalitet

Vad kan besökaren göra på sidan? Vilken fil och vilka funktioner sköter det?
besökaren kan gå igenom hans profil, kompetenser, meriter, arbetserfarenheter och utbildning sen finns det en knapp på kompetenser som man kan se mer och de finns en knapp till personligt brev och sedan tillbaka till cv. Knappen Visa mer styrs av JavaScript-filen script.js, där funktionen visaMer() används för att visa och dölja fler kompetenser. Navigeringen mellan CV och personligt brev sker med HTML-länkar.

## Tekniska val (VG)

Vilka beslut tog jag, och varför?
Jag valde att bygga ett CV eftersom det kändes som ett bra första projekt med tanke på mina nuvarande kunskaper inom programmering.

Jag valde att använda Flexbox för att dela upp mitt CV i två kolumner, eftersom jag ville ha profil och kompetenser på vänster sida och arbetslivserfarenheter och utbildning på höger sida. Jag använde också en media query för att kolumnerna skulle hamna under varandra på mindre skärmar.

Jag valde även att använda AI som ett par extra ögon för att gå igenom min kod. Jag tycker att AI är användbart för att dubbelkolla mitt arbete eftersom det snabbt kan hitta fel och förklara dem för mig.

## Bedömning av AI-innehåll (VG)

Hur avgjorde jag om det AI gav mig var bra nog
Jag avgjorde om AI:s förslag var bra genom att testa dem själv och sedan bedöma om de fungerade som jag ville. Jag tyckte att AI var användbart eftersom det hjälpte mig att hitta småfel i min kod som jag kanske inte hade upptäckt själv eller hade det tagit mycket längre tid. Jag använde därför AI som ett par extra ögon för att dubbelkolla mitt arbete.

Jag märkte också att AI inte alltid gav mig rätt lösning. När jag försökte ändra marginalerna på mitt personliga brev fick jag flera förslag som inte gjorde någon synlig skillnad. Då fick jag själv testa och ifrågasätta förslagen i stället för att bara använda allt AI gav mig.
